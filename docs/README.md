# DriftLauncher Documentation

This folder contains the full documentation for **DriftLauncher**, a custom community launcher for *Last Oasis*. Use it as a reference for what the launcher does, how it works internally, and how to build or extend it.

## For users

- [Getting Started](./getting-started.md) — Install, run, and use the launcher.
- [Realm Browser & Map](./realms.md) — Browse servers, view realm maps, track walkers.
- [Mod Manager](./mods.md) — Install, update, toggle, and auto-activate Workshop mods.
- [News](./news.md) — Steam news feed with read tracking.
- [Settings & Data Storage](./settings.md) — Preferences, themes, backend list, where files live on disk.

## For developers and contributors

- [Architecture](./architecture.md) — Project structure, processes, data flow.
- [Authentication](./authentication.md) — Steam ticket + Last Oasis login pipeline.
- [Backends](./backends.md) — Multi-backend support and the Drift mod-consensus service.
- [IPC Reference](./ipc-reference.md) — All renderer↔main IPC channels.
- [Build & Release](./build-and-release.md) — How to package portable Windows builds.
