# Build & Release

DriftLauncher is built with `electron-vite` and packaged with `electron-builder`. All commands run from the repo root.

## Prerequisites

- Node.js 20+
- pnpm 9+
- Steam running (for development — Steamworks SDK init)
- Last Oasis installed via Steam (App ID `903950`)

## Install dependencies

```bash
pnpm install
```

This installs both `apps/launcher` and the workspace packages (`packages/shared`, `packages/lo-protos`).

## Development

```bash
pnpm --filter launcher dev
```

Starts:

- The Vite dev server for the renderer with HMR.
- An Electron main-process bundle in watch mode.
- A preload bundle in watch mode.

The Electron window launches automatically once the bundles are ready. The window is connected to Steam (must be running) and uses your real Steam identity — there's no offline mode.

### Dev-only flags

- `LOG_LEVEL=debug` — verbose protobuf dumps in the LO HTTP client.
- `DRIFT_BACKEND_URL=...` — point the Drift mod-consensus client at a different host.

Set these in your shell before `pnpm --filter launcher dev`.

### Type checking

```bash
pnpm --filter launcher typecheck
```

Runs `tsc --noEmit` against both `tsconfig.json` (renderer/preload) and `tsconfig.node.json` (main + scripts).

## Building bundles

```bash
pnpm --filter launcher build
```

Compiles main, preload, and renderer into `apps/launcher/out/`. This is a no-package build — useful for sanity checks before running `dist`.

## Regenerating the icon

```bash
pnpm --filter launcher icon
```

Runs `apps/launcher/scripts/generate-icon.js`, which rasterises `src/renderer/assets/drift_launcher.svg` into a multi-size `.ico` at `resources/icon.ico` (sizes 16, 24, 32, 48, 64, 128, 256). Run this after editing the SVG; commit the resulting `.ico`.

## Packaging a Windows release

```bash
pnpm --filter launcher dist
```

Runs `electron-vite build` then `electron-builder`. Output lands in `apps/launcher/dist/`:

- `DriftLauncher-<version>-win-x64.exe` — single-file portable build.
- `DriftLauncher-<version>-win-x64.zip` — zipped unpacked build.

The `dist` step bundles:

- Compiled main / preload / renderer bundles (`out/**`)
- `resources/icon.ico`
- `package.json` (for app metadata)
- `steam_api64.dll` and `steam_appid.txt` (extra files at app root)
- `packages/lo-protos/Protos/` (extra resource at `Protos/`)
- `node_modules/steamworks.js/` (asar-unpacked so the native module loads)

Builds are **unsigned**. Windows SmartScreen will warn on first run.

## Versioning

The version comes from `apps/launcher/package.json` (`"version"` field). `electron-builder` substitutes it into the artifact name (`DriftLauncher-${version}-${os}-${arch}.${ext}`).

To cut a release:

1. Bump the `version` field in `apps/launcher/package.json`.
2. Update `apps/launcher/src/renderer/pages/ChangelogPage.tsx` with the new entry.
3. Commit, tag, push.
4. Run `pnpm --filter launcher dist` and upload the artefacts to GitHub Releases.

## Project structure recap

```
apps/launcher/
├── electron.vite.config.ts   # main / preload / renderer bundle config
├── postcss.config.js         # Tailwind / autoprefixer
├── tailwind.config.js
├── tsconfig.json             # renderer + preload
├── tsconfig.node.json        # main + build scripts
├── resources/icon.ico        # window icon (regenerated by `pnpm icon`)
├── scripts/generate-icon.js
├── steam_api64.dll           # Steamworks runtime (must ship with app)
├── steam_appid.txt           # contains "903950"
└── src/
    ├── main/                 # Node (privileged)
    ├── preload/              # contextBridge surface
    └── renderer/             # React UI
```

Workspace packages:

```
packages/
├── shared/        # TypeScript types crossing the IPC boundary
└── lo-protos/     # Last Oasis .proto files + openapi.yaml
```
